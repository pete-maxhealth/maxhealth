How it works
  1. Export data from Withings or RingConn and drop the zip into:
    /storage/emulated/0/MaxHealth/data/inbox/
  2. Select a device above and tap Generate Command
  3. Copy the command and paste it into Termux, then run it
  4. Paste the Termux output back here to confirm success
  5. Tap Select combined.csv above to load your data into History and Trends
