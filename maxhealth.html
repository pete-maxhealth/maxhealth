⚠ Amazfit / Zepp Note
The Zepp app exports an AES-256 encrypted zip. The password is displayed on screen at the time of export — note it down immediately. Pass it to the pipeline with --password YOUR_PASSWORD or it can't be opened. The password is unique per export, so you'll need it each time.

How it works
  1. Export data from your wearable — do not rename the file
  2. Run bash distribute.sh from the repo — it moves exports from your Download folder to the inbox automatically
  3. Or copy the file manually to the inbox folder shown above
  4. Select your device above and tap Run Pipeline
  5. Copy the command and paste it into Termux, then run it
  6. Paste the Termux output back here to confirm success
  7. Tap Select combined.csv above to load your data
  8. For new devices not listed, use Add New Device below
