Import data from Withings, RingConn, Garmin, Oura or any device that exports CSV. The pipeline runs locally on your phone via Termux and outputs a combined.csv file — load it here to populate your Trends charts.

How it works
▸
  1. Install Termux from F-Droid and run the one-command setup from GitHub
  2. Export data from your wearable and drop the zip into:
    /storage/emulated/0/MaxHealth/data/inbox/
  3. Run the pipeline in Termux:
    python update_health.py
  4. Come back here and tap Load combined.csv
Import Nutrition History (master.csv)

Import a pipe-delimited nutrition log. Existing days are never overwritten.

Format: DD/MM/YY|Calories|Protein|Carbs|Notes
Example: 09/05/26|2840|173|40|stir fry
