v3.10.465
August 2026
Major Release
New — Site-Wide Search & Condition Periods
Site-wide search — one search box (🔍 in the header) covering Library, Recipes, Saved Prompts, and every Settings section. Ask naturally and it finds the right place, even for things like device sync settings that don't have the brand name in their label
Migraine and Cluster Headache added as full conditions, with real research behind both — genuine trial evidence, honestly framed as promising rather than established the way GBM/epilepsy's protocols are
Condition History — automatically tracks when your condition genuinely changes, so a later switch can't retroactively distort how old data gets judged. Ask AI and Full Summary can now naturally compare periods — just ask, no filter needed
Onboarding now offers all 9 conditions instead of 4 — Epilepsy, Strict Keto, Type 1 Diabetes, Migraine and Cluster Headache were previously only reachable by switching later in Settings
New — Polyols & Net Carbs
Polyols now subtracted from net carbs alongside fibre, matching UK/EU convention — genuinely relevant given how often keto recipes lean on erythritol and similar sweeteners. Sourced only from real barcode data, never guessed
Fixed eight separate places that were still checking raw carbs directly instead of the net-aware figure — most visibly the ketosis status badge, which could disagree with the number sitting right next to it depending on the Net Carbs setting
Fixed — Recipes & Data Accuracy
A single broken ingredient could silently blank an entire recipe's ingredient list with no visible error — now shows the other items correctly plus a specific, diagnosable error for the broken one
Substitute picker pre-fill bug — swapping a flagged ingredient pre-filled search with the whole raw label instead of just the food name, finding poor matches until manually retyped
Library picker had no reachable cancel button on a long list — added a sticky close button that stays visible regardless of scroll position
The AI's actual condition-awareness table was missing three conditions (Migraine, Cluster Headache, Body Recomposition) — meaning AI advice was silently generic for them despite the UI looking condition-specific. Fixed with real evidence for each
In Progress — Health Connect (Android)
Server-side pipeline fully built and tested for reading wearable/phone data via Android's Health Connect — a standard integration point replacing fragile per-vendor export parsing. Native companion app written; first build pending

Recipe totals bug — a mislabelled library portion (1g instead of 100g) caused a 1000× scaling error on any recipe using it. Fixed with a plausibility check plus one shared scaling function replacing three separate copies
Vitals score contradicted itself — scored HRV against a fixed population target while the pattern-learning backend judged the same reading "Excellent" against your own baseline elsewhere in the same app. Now consistent
AI Reports fabricated a fat target (a hardcoded 247g shown as if real whenever the actual target was missing) and separately answered "today" questions using yesterday's data, since this app only rolls today into history at midnight. Diabetes condition silently did nothing — onboarding saved it under a different internal name than everywhere else checked for, and changing condition later via Settings never updated your carb ceiling despite promising to. Both fixed

Patterns card's "not enough history" message was misleading against a large total day count — it needs paired wearable-sync data specifically, not just logged nutrition days. Now shows the real counts for each
v3.10.296
August 2026
Major Release
New — Continuous Voice Input
Extended from Recipe Builder to meal logging, missed-day logging, library batch-add, and supplements — say several things in one go, say "done" (plain English works too — "I've finished now", "that's everything") to wrap up. Tap the mic mid-flow to pause, tap again to resume exactly where you left off.
Meal logging never auto-logs from voice — captured items land in the message box and still need the same explicit "Log it" tap as typing does, no matter how many items you said.
Library batch-add — new 🎤 panel on the Library tab, each spoken food + amount goes through the same duplicate/plausibility check manual entry already gets.
Supplements — say each name as you take it, ticks it off your real saved list for the current time of day. Only ever marks taken, never un-marks, so a misheard repeat can't accidentally untick something.
Single-shot voice for weight and water — one value, said once, no "done" needed.
Fixed
Meal-voice pause dead-end — manually tapping the mic (instead of saying "done") previously left captured items with no way to log them without resuming and saying "done" first. Now offers "Log it" either way.
Added a persistent status line so it's visible on-screen the mic is listening in multi-item mode, not just a toast that disappears in a few seconds.
Infrastructure
Cloudflare Worker now enforces a server-side per-IP daily cap and a hard monthly cost ceiling (~£24-30/month worst case, regardless of how many people use the shared proxy) via Workers KV — previously unbounded and scaling linearly with adoption.
v3.10.272
July 2026
Major Release
New
Log food to a past day — from History, add a forgotten or mis-logged item to any previous day through the same AI-parsing pipeline used for today. Recalculates that day's totals automatically.
Multi-AI consensus check — verify any logged item against Claude, Gemini, and ChatGPT independently, one tap. Agreement is reassuring; disagreeing by more than 25% on calories means find a real label, don't trust any of them. Each provider's own numbers checked for internal consistency too.
Activity Credit Balance — rolling-window tracking of exercise calorie credit earned vs actually eaten back, built from real history. A single day under an exercise-boosted target is harmless; this surfaces the pattern if it's happening often enough to add up.
Phase-aware calorie context — Remaining Today now distinguishes harmless unclaimed exercise credit from genuine under-eating, worded for your actual Goal/Phase.
440ml Pint preset added to the hydration bar
AI Reliability — the big one this release
Cloudflare Worker was silently forcing a smaller model and a hard 500-token cap on every proxy-routed call (the default for the entire cloud version) regardless of what any feature actually requested — now forwards the real request
Direct personal API key path had two structural bugs — a missing request body, and a missing browser-security header required by Anthropic's API — meaning it likely never fully worked from a browser since it was first built
Gemini and OpenAI added as additional providers for the consensus check, including automatic retry on transient "high demand" errors
Data Pipeline
Sleep sync had silently stalled at a fixed date for over a week — a folder restructure broke the path the sync button used to find its own extractors; fixed, and a stray disconnected duplicate script removed
Cloud deployment found to be roughly 100 versions behind local — a silent push failure with no error surfaced; deploy script now verifies the push actually landed before reporting success
Bug Fixes
Whole-item scaling bug — correcting a can/bottle's displayed size to its true amount could multiply already-correct values instead of leaving them alone; fixed, plus live auto-scaling added to the ingredient edit screen, which previously had none at all
Two fuzzy-match false-positive causes fixed — an unrecognised brand letting a false match slip through on generic word overlap, and apostrophes (Tennent's, McDonald's, etc.) breaking matching entirely as raw text
Processed meat products (sausage, chorizo, black pudding) were having their real carbs wrongly zeroed by a correction meant only for plain meat/fish
"Haven't eaten this" wasn't always being honoured — a food explicitly marked as not eaten could still end up logged as if it had been; fixed
Exercise-credit banner was a flat-rate guess completely disconnected from the dashboard's own real calculation — could show a wildly different number for the same day's exercise; unified onto one calculation
Manage screen was defaulting every section open on every visit despite a collapse mechanism already existing for exactly this — fixed
Website
Donation messaging corrected to honestly reflect real costs, reframed toward supporting the project rather than personal expenses
Story and patient guide converted from third to first person throughout
