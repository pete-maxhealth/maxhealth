Local setup on your Android phone

This is the guide for the Premium local version: automatic wearable sync, full offline mode and your data on your own phone.

Easier option: the MaxedHealth launcher app automates most of these steps and keeps wearable data syncing in the background. It is not a Play Store app, so Android will say it is from an “unknown source” on install. That is expected. Ask for the launcher and setup help at pspence@pspence.co.uk.
  1. 1

    Install Termux from F-Droid

    Search F-Droid for Termux and install it. Do not use the Play Store version — it's outdated. F-Droid is a free app store at f-droid.org.
  2. 2

    Open Termux and run one command

    Paste this into Termux and press Enter — it does everything automatically:

    curl -sL https://pete-maxhealth.github.io/maxhealth/setup.sh | bash

    When prompted, tap ALLOW to grant storage access.
  3. 3

    Open Chrome and go to localhost:5757

    The setup script starts the server automatically. Open Chrome, type localhost:5757 and bookmark it or Add to Home Screen.
  4. 4

    Minimise Termux — don't close it

    The server runs in the background. Swipe Termux away (don't force-stop it) and MaxedHealth stays running. It starts automatically every time you open Termux.
  5. 5

    Optional: auto-start after reboot

    Install Termux:Boot from F-Droid. MaxedHealth will start automatically after your phone restarts — no need to open Termux manually.
