The core loop

Your daily workflow

MaxedHealth is built around a simple daily rhythm. Once it's habit, each step takes under a minute.

⚖️
Morning
Log your weight
On the Dash tab, tap UPDATE. Weigh yourself first thing — naked, after the bathroom, before eating. Same conditions every day makes the trend meaningful.
💡 Why it matters
Daily weight fluctuates 1–2kg from food, water, and digestion. One number means nothing. Thirty numbers tell the real story.
🍳
Throughout the day
Log meals as you eat them
Tap Log Meal and describe what you ate in plain English. The AI identifies the food and calculates macros. No calorie counting, no barcode scanning.
2 scrambled eggs with butter and smoked salmon
chicken thigh 180g with roasted broccoli
100g ASDA roasted salted mixed nuts
double cream shake — 150g cream
✓ Pro tip
For foods you eat every day, save them to your Library with locked macro values. One tap to log — no AI, no drift.
🌙
End of day
Close out and save your row
When you're done eating, type any of these in the Log Meal box:
that's me done  ·  done for today  ·  all done  ·  wrapping up
MaxedHealth generates your daily nutrition summary and a master.csv row — copy it to your nutrition log file. This is how your history builds permanently.
⚠ Don't skip this
The daily row is only generated at close-out. Without it, the day isn't saved to History. If you forget, log missed meals the next day before closing out.
🎯
Optional
Set your day mode
Tell the app what kind of day it is:

🟢 Standard — normal day, full carb ceiling applies
🟡 Occasion — social event, slightly more flexibility
🔴 Holiday — holiday mode, ceiling not enforced

The ketosis badge and AI feedback adjust automatically.
Data files

Two files. Both important.

MaxedHealth uses two CSV files for different purposes. Here's exactly what each one is.

📋
master.csv — your nutrition history
A plain text file you build over time. One row per day, pipe-delimited:
DD/MM/YY|Calories|Protein|Carbs|Notes
09/05/26|2840|173|40|chicken and broccoli
10/05/26|3100|155|62|holiday meal

Where it comes from: end-of-day close-out generates a row — copy and paste it into this file.

How to import: Import tab → Import Nutrition History → select your file.

Why it matters: your permanent offline record. Even if you clear the app, this file survives. Keep it backed up.
📊
combined.csv — your wearable data
Pipeline output. One row per day, merged from all connected devices — steps, sleep stages, heart rate, HRV, SpO2, weight.

Where it comes from: the pipeline in Termux reads your device exports and writes this file.

How to import: Import tab → Load combined.csv:
/storage/emulated/0/maxhealth/data/tables/combined.csv

What it unlocks: the Trends tab. Sleep, activity, HR plotted over time alongside your nutrition.
Pipeline

Connecting wearable devices

MaxedHealth reads the export files wearable apps produce. The pipeline merges them into combined.csv.

📲
Quickest method
Export and run distribute.sh
Export from your wearable app — the file lands in Download. Open Termux and run:
cd /storage/emulated/0/maxhealth/app/maxhealth && bash distribute.sh
Finds the export, moves it to inbox, offers to run the pipeline. One command, done.
⚙️
Manual method
Run the pipeline directly
Copy your export to the inbox, then:
cd /storage/emulated/0/maxhealth/app
python update_health.py --device withings
python update_health.py --device ringconn
python update_health.py --device amazfit
Full guide: Pipeline Setup →
⚠ Amazfit / Zepp
The Zepp app exports an AES-256 encrypted zip. Use ZArchiver (free, Play Store) to extract it to the inbox folder first. The pipeline detects the extracted folders automatically — no password needed.
📥
Final step
Import into the app
Import tab → Load combined.csv. Your Trends and History are now populated with wearable data alongside nutrition.

Protect your data

Back up regularly.
Seriously.

MaxedHealth stores everything in Chrome's localStorage — fast and private. But if Chrome clears its storage, it's gone. Three habits keep you safe.

📤
Weekly habit
Export your JSON backup
Settings → Export Backup Now (JSON). Saves everything — history, library, settings, targets. Save to Google Drive or email to yourself.
⚠ Don't assume it's safe
Chrome can clear localStorage when the device runs low on storage, when you clear browsing data, or during a reset. Export weekly.
📋
Daily habit
Keep master.csv
Copy your daily row to a plain text file after every close-out. Works independent of the app — readable in any spreadsheet, importable anywhere.
🔄
Automatic
Pipeline backups
Every pipeline run backs up combined.csv and nutrition.csv automatically. Up to 7 rotating backups at:
/storage/emulated/0/maxhealth/data/backup/
Restore via Import tab → Restore Backup.
Common questions

FAQ

I logged a meal but the macros look wrong. How do I fix it?
Tap the meal in today's log and edit the values. Save the corrected version to your Library with locked values — the AI uses your numbers next time.
What's the difference between Log Meal and the Library?
Log Meal uses AI to identify macros from a description. The Library stores foods you eat regularly with locked values — one tap to log, no AI needed.
Will I lose my data if I clear Chrome?
Yes — clearing site data wipes localStorage. Export regularly: Settings → Export Backup Now. Keep master.csv backed up separately.
Why does the Trends tab show no data?
Trends needs combined.csv from the pipeline. Meal logging alone won't populate it. Connect a wearable or import a combined.csv from the Import tab.
Can I use MaxedHealth on multiple devices?
Not automatically — data lives locally on each device. Export from one (Settings → Export All Data) and import on another.
Is my data sent anywhere?
Only meal descriptions go to Claude AI for macro identification. Nothing else leaves your device. No accounts, no cloud storage, no tracking.
How do I change my carb ceiling?
Settings → Carb Ceilings. Set different ceilings for standard, occasion, and holiday days independently.
What does "that's me done" actually do?
Triggers end-of-day close-out — calculates daily totals, generates a summary, produces a master.csv row, and saves the day to History.
The AI got the macros wrong. Can I override it?
Yes — edit the values after logging, then save to your Library with locked values. Library always takes precedence over AI estimates.
