Setup Steps
Samsung Galaxy users: Before installing, go to Settings → Security and Privacy → Auto Blocker and turn it off temporarily. Turn it back on after setup is complete.
STEP 1
Install F-Droid, Termux and Termux:Boot

F-Droid is an open-source app store. Install it first, then use it to install Termux and Termux:Boot.

Why F-Droid and not the Play Store? The Play Store version of Termux is outdated and won't work correctly.

Get F-Droid → Get Termux → Get Termux:Boot →
After installing Termux:Boot, find its icon in your app drawer and tap it once to activate it. It won't open anything visible — that's normal.
STEP 2
Run the one-command setup

Open Termux and paste this single command, then press Enter:

curl -sSL https://raw.githubusercontent.com/pete-maxhealth/maxhealth/main/setup.sh | bash

This automatically installs Python, downloads the MaxedHealth pipeline, creates the folder structure, sets up auto-start on boot, and starts the server. Takes about 2 minutes.

After setup completes, restart your phone. The server will start automatically on every reboot — you never need to touch Termux again for normal use.
STEP 3
Export data from your wearable — and don't rename the file

Withings: Open the Health Mate app → Profile → Download my data. You'll receive a zip by email — the filename starts with export_.

RingConn: Open the RingConn app → Profile → Export data. You'll get a CSV — filename typically contains RingConn or ring.

Amazfit / Zepp: Open the Zepp app → Profile → Settings → Export Health Data. A password will be shown on screen — write it down immediately, you cannot recover it later. The zip filename is your numeric user ID, e.g. 7084918973_1778514144808.zip. Keep this exact filename.

Other devices: Export a CSV from your device's app. Any CSV with a date column works — use Add New Device in the Import tab.

Important: Do not rename export files before copying them to the inbox. The pipeline identifies your device by the original filename. Renaming causes silent detection failure.

Copy the file to the inbox folder — do not unzip it:

/storage/emulated/0/maxhealth/data/inbox/
STEP 3b — THE EASY WAY
One-tap sync — no Termux needed

After the one-time setup, you never need to open Termux again for normal use. The local server runs automatically in the background on every boot.

Open MaxedHealth → Import tab → tap SYNC NOW. The app will:

  1. Scan your Download folder for wearable exports
  2. Move them to the inbox automatically
  3. Run the pipeline
  4. Load the result directly into Trends & History
Green dot in the Import tab means the local server is running and ready. If you see a grey dot, open Termux once and run: cd /storage/emulated/0/maxhealth/app && python server.py & — after your next reboot it starts automatically.
Amazfit / Zepp only: Zepp export zips are AES-256 encrypted and must be extracted manually first. Open ZArchiver (free, Play Store) → navigate to the inbox → tap the zip → Extract → enter your Zepp password. Then tap Sync again.
STEP 4 — ADVANCED ONLY
Manual pipeline (Termux fallback)

For advanced use — running specific devices, dry-run mode, or debugging. The Import tab also has per-device buttons under Advanced / Manual Pipeline.

cd /storage/emulated/0/maxhealth/app
python update_health.py # all devices
python update_health.py --device withings
python update_health.py --device ringconn
python update_health.py --device amazfit
python update_health.py --dry-run # preview only

After running manually, go to Import tab → SELECT FILE MANUALLY and load combined.csv from:

/storage/emulated/0/maxhealth/data/tables/combined.csv
The pipeline automatically backs up your existing data before writing. If anything goes wrong, restore via Import tab → Restore Backup.
Adding a New Device
ANY CSV DEVICE
AI-powered column mapping

MaxedHealth can work with any device that exports CSV data — Garmin, Oura, Fitbit, Apple Health, or even a spreadsheet you've been keeping yourself.

In the MaxedHealth app, go to Import → Add New Device. Upload a sample CSV export. The AI will inspect the headers, detect column mappings and units (kg vs lbs, minutes vs hours), and show you a confirmation screen with a 3-row preview before saving anything.

Once confirmed, the device config is saved and used automatically every time you run the pipeline.

Source Precedence

When multiple devices report the same metric for the same date, the pipeline uses the highest-priority source and fills gaps with secondary sources.

Default order:

Metric Priority order
WeightWithings → manual → RingConn → Amazfit
HRVRingConn → Withings → Garmin
SleepRingConn → Withings → Garmin → Amazfit
StepsGarmin → Withings → RingConn → Amazfit
SpO2RingConn → Withings
Heart RateRingConn → Amazfit → Withings → Garmin

To change the order for your setup: open MaxedHealth → Import tab → Source Precedence. Changes apply on the next pipeline run.

Backup & Restore

Before every pipeline write, your current combined.csv and nutrition.csv are automatically copied to:

/storage/emulated/0/maxhealth/data/backup/

Files are named with a timestamp, e.g. combined_20260511_143022.csv. A maximum of 7 backups are kept — the oldest is deleted when a new one is created.

To restore: open MaxedHealth → Import tab → Restore Backup. Select the backup you want and confirm. The restored file becomes the active combined.csv immediately.

Pipeline Error Log

Every pipeline run writes a structured log to:

/storage/emulated/0/maxhealth/pipeline.log

Each line records: timestamp, device, operation, status, and message. Example:

2026-05-11 14:30:22 | amazfit   | extract | ok     | 2 days processed
2026-05-11 14:30:22 | withings | extract | warn   | No files found in inbox/
2026-05-11 14:30:22 | pipeline | write   | ok     | combined.csv written (847 rows)

The last 50 lines are also visible inside the app: Import tab → View Pipeline Log. Errors are surfaced in the UI — nothing fails silently.

Troubleshooting

Sync button is grey / server offline? The local server hasn't started yet. Open Termux and run: cd /storage/emulated/0/maxhealth/app && python server.py & — after your next reboot it will start automatically via Termux:Boot.

Server not starting after reboot? Make sure you tapped the Termux:Boot icon once after installing it. Then restart your phone again.

Pipeline failing? Check the log file at /storage/emulated/0/maxhealth/server.log

Can't find the inbox folder? Open your Files app and navigate to Internal storage → MaxedHealth → data → inbox

Still stuck? Open an issue on GitHub.
