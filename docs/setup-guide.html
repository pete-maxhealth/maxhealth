Before you start

Install three free apps

These come from the Play Store and take about 2 minutes. You'll only ever do this once.

1
Install Termux
👆 Tap required 🔁 One-time
Termux is a Linux terminal for Android. It runs the wearable data pipeline behind the scenes.

Play Store → search "Termux" → install the one by Fredrik Fornwall.

Do not install from the Google Play Store's Termux — it's outdated. Install from F-Droid for the latest version.
⚠ Use the F-Droid version of Termux, not the Play Store version. The Play Store version is unmaintained and will fail during package installation.
2
Install Termux:Boot
👆 Tap required 🔁 One-time
Termux:Boot starts the MaxedHealth local server automatically every time your phone restarts. This is what makes the app available at localhost:5757 without you ever opening Termux.

F-Droid → search "Termux:Boot" → install.

After installing, find Termux:Boot in your app drawer and tap it once to activate it. Nothing visible will happen — that's normal.
Important: After setup is complete, restart your phone once. From that point on, the server starts automatically on every reboot — no Termux needed.

Tip: Run this once in Termux to add a handy shortcut:
echo 'alias mhstart="pkill -f server.py 2>/dev/null; sleep 1; cd /storage/emulated/0/maxhealth/app && python server.py &"' >> ~/.bashrc && source ~/.bashrc

After that, typing mhstart in Termux safely restarts the server whenever needed.
Setup

One command, everything else is automatic

Open Termux, paste this exactly, and press Enter. The script handles everything — packages, folders, repo, pipeline, shortcuts.

3
Open Termux and paste
👆 One tap
Open the Termux app, tap the screen to focus, then paste this command:
Termux
curl -sSL https://raw.githubusercontent.com/pete-maxhealth/maxhealth/main/setup.sh | bash
What this does: Downloads the setup script from GitHub and runs it. No admin access, no system changes — everything goes into Termux's own storage.
4
Tap Allow on the storage popup
👆 Required tap
Almost immediately, Android will show a permission popup:

"Allow Termux to access files?"

Tap Allow. This is the only Android permission popup. Without it, the pipeline can't read your wearable exports from the Download folder or write the processed data file.

This is an Android security requirement — it cannot be granted automatically.
⚠ The popup appears within the first few seconds. Watch for it — if you miss it, the script will fail and you'll need to run it again.
5
Wait ~2 minutes
⚡ Automatic
The script now runs completely silently. It will:

✓ Update package lists
✓ Install Python, Git, curl, openssh
✓ Create all required folders
✓ Clone the MaxedHealth repo
✓ Copy pipeline extractors
✓ Create the home screen sync shortcut
✓ Set up auto-sync on boot
✓ Configure Git identity
✓ Open MaxedHealth in your browser

You'll see progress messages. When it says Setup complete! 🎉 — you're done.
After setup

Two final one-time steps

The app is running. These steps connect your physical data to it.

6
Add MaxedHealth to your home screen
👆 One tap 🔁 One-time
Once the app opens, you'll see a green nudge bar at the top:

📲 Add to Home Screen for the best experience

Tap Install → and confirm. MaxedHealth will appear on your home screen as an app icon — no browser bar, opens directly to your local server, always on the right URL.

This is the permanent fix for the URL question — from here on, just tap the icon.
Why this matters: The home screen shortcut always opens localhost:5757 — your local device. The one-tap Sync button in the Import tab works from here. If you ever use the GitHub URL directly, it redirects automatically when your server is running.
7
Complete onboarding in the app
👆 A few taps 🔁 One-time
The app opens automatically at localhost:5757. If it doesn't open automatically, tap that link.

You'll see the onboarding wizard. It asks for your name, current weight, target weight, and health profile. Takes about 90 seconds.

Your goal is inferred automatically — if your target is higher than your current weight, it sets Gain. Lower sets Lose. Same sets Maintain. You can override this on the next screen if needed.
Ongoing use

Syncing your wearable data

Export from your device app, tap SYNC NOW in the Import tab, and your data loads automatically. Takes under a minute.

📱 RingConn
  1. Open RingConn app
  2. Profile → Export data
  3. File lands in Downloads automatically
  4. Open MaxedHealth → Import tab → tap SYNC NOW
  5. Data loads automatically — done
⚖️ Withings
  1. Open Health Mate app
  2. Profile → Download my data
  3. File arrives by email — save to Downloads
  4. Open MaxedHealth → Import tab → tap SYNC NOW
  5. Data loads automatically — done
⌚ Zepp / Amazfit
  1. Open Zepp app → Profile → Settings → Export Health Data
  2. Note the password shown — write it down immediately
  3. File lands in Downloads as a numeric zip
  4. Open ZArchiver → navigate to Downloads
  5. Tap the zip → Extract here → enter Zepp password
  6. Open MaxedHealth → Import tab → tap SYNC NOW
  7. Data loads automatically — done
⚠ Zepp zips are AES-256 encrypted. ZArchiver (free, Play Store) is required to extract them before syncing.
🏃 Garmin
  1. Garmin Connect → More → Export/Import
  2. Export as ZIP or CSV
  3. Save to Downloads folder
  4. Open MaxedHealth → Import tab → tap SYNC NOW
  5. Data loads automatically — done
⚠ Garmin extractor is a work in progress — limited fields supported currently.

FAQ

Questions & answers

The things people actually ask.

Does this work on iPhone? +
Not currently. The pipeline relies on Termux which is Android-only. The web app itself (maxhealth.html) works on any browser including Safari on iOS — but the wearable sync pipeline requires Termux on Android. An iOS-compatible pipeline is on the roadmap.
Is my health data sent anywhere? +
No. All data lives on your device. The pipeline runs locally in Termux. The app stores everything in your browser's localStorage. The only external connection is the AI assistant — which uses the Anthropic API via a Cloudflare proxy. No health data is sent to any server.
What if the storage permission popup appears and disappears before I tap it? +
Just run the setup command again. The script checks whether storage is accessible and will re-trigger the popup. You can run setup as many times as you like — it's safe to repeat.
Why F-Droid instead of Play Store for Termux? +
The Play Store version of Termux stopped being updated in 2020 due to Google Play restrictions. It ships with outdated package repositories and package installation will fail. F-Droid distributes the current maintained version. F-Droid itself is free and open source — just install it once and search for Termux from there.
My RingConn / Withings data isn't showing up after sync. +
After syncing via the Import tab → SYNC NOW button, data loads automatically. If you ran the pipeline manually via Termux, go to Import tab → Select File Manually and navigate to /storage/emulated/0/maxhealth/data/tables/combined.csv.
Can I use MaxedHealth without wearables at all? +
Absolutely. The app works perfectly as a nutrition tracker without any wearable data. Log meals via the AI assistant, track weight manually, and use the Reports tab to analyse your nutrition history. The Trends tab will show "no data" for wearable metrics until you sync a device.
What's the difference between localhost:5757 and the GitHub URL? +
localhost:5757 is MaxedHealth running directly on your phone — this is the real app. The GitHub URL (pete-maxhealth.github.io) is the entry point used for sharing and initial setup. When your local server is running, the GitHub URL automatically redirects to localhost:5757. When it's not running, the GitHub URL works in cloud mode — AI logging works but the one-tap wearable sync is unavailable. The home screen shortcut always opens localhost:5757 directly, which is why installing it is recommended.
The app shows a grey dot and says the server isn't running. What do I do? +
The server may have stopped, or a second instance failed to start (which is harmless — the first is still running). Open Termux and type mhstart — this is a shortcut that safely restarts the server. Then reload the app.

If mhstart isn't recognised yet, run the full command once:
pkill -f server.py 2>/dev/null; sleep 1; cd /storage/emulated/0/maxhealth/app && python server.py &

After your next phone reboot, the server starts automatically via Termux:Boot. If it keeps failing after reboots, make sure you tapped the Termux:Boot icon once after installing it.
How do I uninstall everything? +
Uninstall Termux and Termux:Boot from your app settings. Delete the MaxedHealth home screen shortcut. Delete the /storage/emulated/0/maxhealth/ folder from your file manager. Clear site data for localhost and pete-maxhealth.github.io in Chrome settings. That's everything — nothing else was installed or modified.
