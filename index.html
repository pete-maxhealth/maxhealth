Want wearable sync? Optional Termux setup
▼

To sync data from Withings, Amazfit or RingConn devices, you need to run a local server on your Android phone using Termux. This is a one-time setup.

1
Install Termux from F-Droid (free, open source). Not the Play Store version — that one is outdated.
f-droid.org → search Termux
2
Also install Termux:Boot from F-Droid — this starts the server automatically when your phone restarts.
3
Open Termux and run this command to download and set up MaxedHealth: curl -sL https://pete-maxhealth.github.io/maxhealth/setup.sh | bash
4
Once setup completes, open the app from your home screen — it will automatically connect to the local server at localhost:5757 and full sync will be available.
💡 After setup, you never need to open Termux again. The server starts automatically when your phone boots and runs silently in the background.
