WHAT IT DOES
Everything in one place
🧠
AI meal logging
Type, speak, photograph or scan a barcode. Claude identifies foods and calculates macros instantly — even complex multi-ingredient meals.
⚡
Ketosis tracking
Real-time ketosis zone indicator, streak counter, and carb ceiling per day mode. Therapeutic GBM protocol, standard keto, or custom targets.
🏃
Activity-adjusted targets
MET-based calorie calculation. Tick walking or resistance and your calorie, protein and water targets update instantly.
📊
Clinical reports
Treatment Analysis, GBM Monthly Summary, Oncology Team View, Weekly Export. Data your medical team can actually use.
🧪
Occasion tagging
Tag chemotherapy days, illness, fasting, social events. See exactly how your nutrition changes around treatment in Reports.
📱
Wearable integration
Withings body composition, RingConn HRV/sleep/SpO2, Amazfit activity — all combined into a single daily dataset.
🔒
Your data, your device
Single HTML file. Runs locally on Android via Termux. No account, no cloud sync, no ads. Data stays on your phone.
🎤
Voice input
Speak your meal and MaxedHealth logs it. Useful when you can't type — post-exercise, mid-cooking, or just easier.
BUILT FOR
Therapeutic protocols

MaxedHealth was designed around a strict therapeutic ketogenic protocol for GBM (glioblastoma multiforme). The same precision works for any condition requiring careful metabolic management.

⚠️
About the live demo Tapping "Open MaxedHealth" opens the app hosted on GitHub Pages. It works fully in your browser — you can log meals, explore features and view reports. However, data is stored in your browser's localStorage and wearable sync requires the local server. For persistent daily use, set up the local version on Android.
LOCAL SETUP
Run it on your Android phone
1
Install Termux from F-Droid Search F-Droid for Termux and install it. Do not use the Play Store version — it's outdated. F-Droid is a free app store at f-droid.org.
2
Open Termux and run one command Paste this into Termux and press Enter — it does everything automatically:

curl -sL https://pete-maxhealth.github.io/maxhealth/setup.sh | bash

When prompted, tap ALLOW to grant storage access.
3
Open Chrome and go to localhost:5757 The setup script starts the server automatically. Open Chrome, type localhost:5757 and bookmark it or Add to Home Screen.
4
Minimise Termux — don't close it The server runs in the background. Swipe Termux away (don't force-stop it) and MaxedHealth stays running. It starts automatically every time you open Termux.
5
Optional: auto-start after reboot Install Termux:Boot from F-Droid. MaxedHealth will start automatically after your phone restarts — no need to open Termux manually.
